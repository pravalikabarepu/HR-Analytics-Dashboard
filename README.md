# HR Analytics Dashboard

## 📊 Project Overview

This project presents an interactive **HR Analytics Dashboard built using Microsoft Power BI**. The dashboard analyzes employee data to understand workforce distribution, employee attrition, salary patterns, experience, age groups, departments, and job satisfaction.

The goal is to provide clear HR insights that can support data-driven workforce decisions.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization
* Business Intelligence

## 📈 Dashboard Highlights

The dashboard includes:

* Total Employees
* Active Employees
* Attrition Count
* Attrition Rate
* Average Age
* Average Experience
* Attrition by Department
* Attrition by Salary Slab
* Age Group Distribution
* Attrition by Gender
* Attrition by Experience
* Employee Count by Department
* Job Role and Satisfaction Analysis

## 🔍 Key Insights

* Analyzed employee attrition across different departments.
* Compared attrition across salary slabs.
* Examined employee distribution by age group and gender.
* Analyzed attrition trends based on employee experience.
* Compared employee counts across departments.
* Studied job roles and satisfaction levels to identify workforce patterns.
* Created interactive visuals to support HR decision-making.
